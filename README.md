## Design Principles

The token contract itself should remain boring.

- No custom transfer logic
- No mutable taxes
- No blacklist
- No pause controls
- No owner privileges
- No hidden mint
- No anti-bot gimmicks
- No trading switches

The absurdity belongs in the Department.
